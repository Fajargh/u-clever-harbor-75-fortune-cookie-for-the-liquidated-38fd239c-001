One fortune cookie line for a crypto trader who just got liquidated — written in a real fortune-cookie voice, with a wry twist on the loss. Warm, rueful, never cruel: your luck turns tomorrow, even if the market kept the change today.

The entry program (`main.ts`, Node 22, stdlib only) writes the single fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Run it

```sh
node main.ts
cat /output/entry.txt
```
